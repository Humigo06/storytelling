# Storytelling in Video Games

A small website exploring key elements of storytelling and how video games use them. It includes an overview of plot, characters, setting, conflict, and theme, plus a closer look at *Fire Emblem: Three Houses*.

## Pages

- `index.html` — Introduces storytelling elements and examples of story-driven games.
- `page2.html` — Discusses how *Fire Emblem: Three Houses* uses those elements.

## View the site

Open `index.html` in a web browser. No build or installation is required. Bootstrap is loaded from a CDN, so an internet connection is needed for its styles.

## Built with

- HTML
- CSS
- Bootstrap 5.3.8
